추천 연속 질문 예시 1

(가장 기본적인 RAG + 메모리)

1. 달콤한 디저트와 잘 어울리는 커피 추천해줘.
2. 그 커피를 차갑게 변경할 수 있어?
3. 디카페인으로도 가능해?
4. 그럼 같이 먹기 좋은 케이크도 추천해줘.
5. 내가 방금 추천받은 음료가 뭐였지?
추천 연속 질문 예시 2

(메모리 테스트용 👍)

1. 아메리카노랑 잘 어울리는 디저트 추천해줘.
2. 너무 달지 않은 걸로 바꿔줘.
3. 그럼 음료는 라떼 계열로 추천해줘.
4. 내가 처음에 어떤 커피를 물어봤었지?
5. 지금까지 추천된 메뉴를 정리해줘.
추천 연속 질문 예시 3

(RAG 검색 정확도 테스트)

1. 초코 브라우니와 잘 어울리는 음료는 뭐야?
2. 왜 잘 어울리는지 설명해줘.
3. 차가운 음료 중에서는 뭐가 가장 잘 어울려?
4. 쓴맛이 강하지 않은 메뉴로 다시 추천해줘.
5. 비슷한 디저트도 추천해줘.
추천 연속 질문 예시 4

(운영 정보 검색 테스트)

1. 매장 운영 시간이 어떻게 돼?
2. 할인 이벤트 시간도 알려줘.
3. 개인 컵 사용하면 혜택 있어?
4. 노트북 사용 가능한 좌석도 있어?
5. 와이파이 제공하나?
추천 연속 질문 예시 5

(시즌 메뉴 검색)

1. 여름 시즌 메뉴 추천해줘.
2. 그 메뉴랑 어울리는 디저트도 알려줘.
3. 겨울 시즌 인기 메뉴는 뭐야?
4. 따뜻한 음료 중 추천해줘.
5. 시즌 메뉴를 정리해서 알려줘.
추천 연속 질문 예시 6

(메모리 + 조합 추천 👍)

1. 커피를 처음 마시는 사람에게 추천할 메뉴는?
2. 너무 쓰지 않은 걸로 해줘.
3. 그 음료와 어울리는 베이커리 추천해줘.
4. 아침에 먹기 좋은 조합으로 다시 추천해줘.
5. 내가 선택한 메뉴 특징을 설명해줘.
추천 연속 질문 예시 7

(옵션 변경 테스트)

1. 카페라떼 주문할게.
2. 오트밀크로 변경 가능해?
3. 얼음은 적게 넣어줘.
4. 당도 조절도 가능해?
5. 지금 주문 내용을 정리해줘.
추천 연속 질문 예시 8

(RAG 문맥 유지 테스트 👍)

1. 초코 케이크와 잘 어울리는 커피 추천해줘.
2. 그 커피의 특징은 뭐야?
3. 비슷한 느낌의 다른 디저트도 추천해줘.
4. 너무 달지 않은 조합으로 바꿔줘.
5. 내가 지금까지 선택한 메뉴들을 정리해줘.
강의용으로 특히 좋은 질문 👍
