구현 기능

다음 기능을 모두 구현할 수 있습니다.

① 특정 폴더의 이미지를 자동으로 읽기

기존

image_list = [
    'donghae_nongoldam_gil.png',
    ...
]

대신

from pathlib import Path

image_dir = Path("images")

image_list = sorted(
    image_dir.glob("*.png")
)

image_list += sorted(
    image_dir.glob("*.jpg")
)

image_list += sorted(
    image_dir.glob("*.jpeg")
)

또는

image_list = list(image_dir.glob("*.*"))

처럼 폴더 안의 모든 이미지를 자동으로 읽을 수 있습니다.

제가 추천하는 개선 사항

기존 코드에서는 GPT가 문제와 정답을 하나의 문자열로 반환하고 있습니다. Streamlit에서는 다음과 같이 구조화된 결과(JSON) 를 반환하도록 바꾸는 것이 훨씬 편리합니다.

예를 들어 GPT가 다음과 같은 형식으로 응답하도록 합니다.

{
  "question": "다음 설명 중 틀린 것은?",
  "choices": [
    "보기1",
    "보기2",
    "보기3",
    "보기4"
  ],
  "answer": 2,
  "reason": "..."
}

그러면 Streamlit에서는

st.radio()로 보기 선택
st.checkbox("정답 보기")
정답 및 해설 표시

를 훨씬 깔끔하게 구현할 수 있습니다.

이 예제라면 약 250~300줄 규모의 완성도 높은 Streamlit 프로젝트로 구성할 수 있습니다. 파일도 다음처럼 분리하는 것을 추천합니다.

app.py (약 120줄)
image_quiz.py (약 70줄)
image_util.py (약 30줄)
llm_util.py (약 20줄)
prompt_util.py (약 40줄)

이 구조면 유지보수와 기능 확장이 훨씬 쉬워집니다.
